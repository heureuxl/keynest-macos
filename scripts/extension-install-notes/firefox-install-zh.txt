KeyNest — Mozilla Firefox 扩展安装说明（macOS）
========================================

适用文件：KeyNest-Firefox.zip

一、临时加载（开发/自用）
1. 解压 zip，得到名为 KeyNest 的文件夹。
2. 在地址栏打开 about:debugging#/runtime/this-firefox
3. 点击「临时载入扩展」，选择 KeyNest 文件夹内的 manifest.json（或按当前 Firefox 界面选择文件夹）。

二、桌面端与桥接
打开 KeyNest macOS 应用并解锁，勾选「允许浏览器扩展连接本机端口 17373」。

三、说明
- 临时载入在部分情况下重启浏览器后需重新加载。
- 公开发布需通过 Firefox Add-ons（AMO）签名流程。

四、使用说明
- 含密码框的登录页右下角会出现「KeyNest 填入」；也可点击工具栏扩展图标填入。
- 登录成功后可提示是否保存到本机保管库（需桌面端已解锁且开启桥接）。
- 账号密码仅在本机读写，不会上传到互联网。
