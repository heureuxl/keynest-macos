KeyNest — Google Chrome 扩展安装说明（macOS）
========================================

适用文件：KeyNest-Chrome.crx（推荐）或 KeyNest-Chrome.zip

一、安装步骤（.crx，推荐）
1. 用 Chrome 打开 chrome://extensions
2. 打开右上角「开发者模式」
3. 将 KeyNest-Chrome.crx 拖入该页面（或双击 crx 并按提示允许）

二、安装步骤（解压 zip）
1. 解压 zip，得到名为 KeyNest 的文件夹（请勿只复制零散文件）。
2. 在 Chrome 地址栏输入 chrome://extensions 并回车。
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选中解压后的 KeyNest 文件夹。

三、桌面端与桥接
打开 KeyNest macOS 应用并解锁，勾选「允许浏览器扩展连接本机端口 17373」。

四、更新扩展
在 chrome://extensions 页面点击 KeyNest 助手旁的「重新加载」；
或移除旧版后，按「一」或「二」重新安装新版。

五、使用说明
- 含密码框的登录页右下角会出现「KeyNest 填入」；也可点击工具栏扩展图标填入。
- 登录成功后可提示是否保存到本机保管库（需桌面端已解锁且开启桥接）。
- 账号密码仅在本机读写，不会上传到互联网。
